Step 1

Get OpenWeatherMap API Key

First we create an account and generate an API key that authorizes our requests.

Why Do We Need an API Key?

  • API key identifies who is sending requests
  • Provider can manage usage limits and access
  • Requests without key are rejected
  • This is common in most public APIs

Create Account (Guided)

  1. Go to openweathermap.org
  2. Sign up and verify your email
  3. Log in and open API keys dashboard
  4. Copy your generated key for class use

Endpoint We Will Use

GET https://api.openweathermap.org/data/2.5/weather
?q={city}
&appid={api_key}
&units=metric

q is city name, appid is your key, units=metric gives Celsius.

API Key Safety Note

  • Never post real keys in public repositories
  • For class demos, keep key local in your file
  • Later we will learn env files and secure setups

Step 5

Add JavaScript Logic

We wire DOM events, call API, and render weather output.

JavaScript - Select Elements

const cityInput = document.querySelector("#city-input");
const searchBtn = document.querySelector("#search-btn");
const statusEl = document.querySelector("#status");
const weatherResult = document.querySelector("#weather-result");

JavaScript - Add API Constants

const API_KEY = "PASTE_YOUR_KEY_HERE";
const BASE_URL = "https://api.openweathermap.org/data/2.5/weather";

JavaScript - Fetch Function

async function fetchWeather(city) {
  const url = `${BASE_URL}?q=${city}&appid=${API_KEY}&units=metric`;
  const response = await fetch(url);
  if (!response.ok) throw new Error("City not found");
  return response.json();
}

JavaScript - Render Function

function renderWeather(data) {
  weatherResult.innerHTML = `
    <h2>${data.name}</h2>
    <p>Temperature: ${data.main.temp} C</p>
    <p>Condition: ${data.weather[0].description}</p>
    <p>Humidity: ${data.main.humidity}%</p>
  `;
}

JavaScript - Button Click Handler

searchBtn.addEventListener("click", async () => {
  const city = cityInput.value.trim();
  if (!city) return;
  const data = await fetchWeather(city);
  renderWeather(data);
});

Add Loading + Error (Minimal)

statusEl.textContent = "Loading weather...";
try {
  const data = await fetchWeather(city);
  renderWeather(data);
  statusEl.textContent = "Done.";
} catch (error) {
  statusEl.textContent = error.message;
}

Final Integration Checklist

  • Search valid city -> weather details shown

Common Beginner Issues

  • Wrong element IDs between HTML and JavaScript
  • Missing API key or typo in query URL
  • Forgetting await in async flow
  • Not checking response.ok before JSON parse
