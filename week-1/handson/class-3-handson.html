Class 3 Lab - Open session deck - Build a mini app, commit history, and deploy to GitHub Pages

Exercise 1 - Build app structure (HTML)

  1. Create a tiny app named Score Helper in the practice area below.
  2. Keep one numeric input (id="score-input"), one button (id="calc-btn"), and one output paragraph (id="result").
  3. Add a short title and one instruction sentence for users.
Done when: app has title, input, button, and output placeholder visible before JavaScript logic.

Exercise 2 - Add reusable functions (JavaScript)

  1. In the script block, write a pure function gradeFromScore(score) that returns one of: A, B, C, F.
  2. Write a second function renderResult(text) that updates #result.
  3. Wire button click: read input, convert to number, call both functions, show output.
Done when: clicking button shows grade text for valid scores.

Exercise 3 - Use one array method

  1. Add an array in script, for example: const sampleScores = [55, 68, 72, 88, 93];
  2. Use at least one method among map, filter, find, or forEach.
  3. Example: create a list of passing scores, or map scores into grade letters.
  4. Display that summary below the main result paragraph (id="summary").
Done when: UI shows dynamic summary generated from an array method.

Exercise 4 - Initialize git and create commit history

  1. In terminal from week-1 folder, run: git init
  2. Create a repository history with at least 3 meaningful commits, such as:
    • feat: add score helper html shell
    • feat: add grading functions and click handler
    • feat: add array summary output
  3. Use git status before each commit to check staged files.
Done when: git log --oneline shows at least 3 clear commits.

Exercise 5 - Push to GitHub

  1. Create a new empty repository on GitHub (do not add README from web if you already have local files).
  2. Connect remote and push: 
    git remote add origin https://github.com/<your-username>/<repo-name>.git
git branch -M main
git push -u origin main
  3. Confirm files appear on GitHub, including index.html at repo root.
Done when: GitHub repository contains your project and commit history.

Exercise 6 - Deploy with GitHub Pages (main branch root)

  1. Rename this file to index.html before deploying (or create a root index that links here).
  2. On GitHub: Settings -> Pages -> Build and deployment -> Deploy from a branch.
  3. Select Branch: main and Folder: / (root), then Save.
  4. Wait for publish message and open: https://<username>.github.io/<repo-name>/
  5. Verify app interaction works on the live URL.
Done when: you can share both repository URL and live GitHub Pages URL.
