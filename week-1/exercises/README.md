# Week 1 Exercises

Use this folder for assignment and practice tasks that are separate from the guided hands-on files.

## Suggested naming

- `exercise-1.md` or `exercise-1.html`
- `exercise-2.md` or `exercise-2.html`
- `project-week1.md`

## Submission format for students

For each exercise, submit:

1. GitHub repository URL
2. Live GitHub Pages URL (when required)
3. Short note on what was completed and what was challenging
