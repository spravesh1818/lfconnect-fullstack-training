Week 1 Student Assignment Sheet

How to Approach This Week

You have learned HTML/CSS basics, Flexbox and Grid, and JavaScript basics. This assignment pushes you to explore more on your own while building mini real-world UI blocks.

  • Complete all five assignments in order (difficulty increases step by step).
  • Each assignment has at most 2 questions: Q1 is core, Q2 is challenge.
  • Use the starter HTML for each part and extend it with your own CSS.

GitHub Submission Note

Add all your assignment work to a GitHub repository so it can be shared and reviewed easily.

Use this structure:

project-root/
  index.html
  style.css
  week-1/
    assignments/

Assignment 1: Semantic HTML Foundations

Objective: Learn semantic tags like article, aside, video, and audio by structuring content properly.

Questions

  1. Q1 (Core): Build a blog page using semantic structure with header, nav, main, article, aside, and footer.
  2. Q2 (Challenge): Inside the article, include one video and one audio element, and explain in a short note why they are placed there.

Starter HTML

<header>
  <h1>My Blog</h1>
  <nav>
    <a href="#">Home</a>
    <a href="#">Articles</a>
  </nav>
</header>

<main>
  <article>
    <h2>Blog Title</h2>
    <p>Write your article content here.</p>
    <video controls width="320"></video>
    <audio controls></audio>
  </article>
  <aside>Related posts or notes</aside>
</main>

<footer>Copyright 2026</footer>

Deliverable: One HTML page where each semantic tag has a clear purpose.

Assignment 2: Basic Tags and Styling Practice

Objective: Practice headings, navbars, images, and basic styling behavior including object-fit.

Questions

  1. Q1 (Core): Build a product hero section with heading, short description, navbar, image, and one CTA button.
  2. Q2 (Challenge): Show three image boxes side-by-side that compare object-fit: cover, contain, and fill.

Starter HTML

<header>
  <h1>Amazing Product</h1>
  <nav>
    <a href="#">Home</a>
    <a href="#">Features</a>
    <a href="#">Contact</a>
  </nav>
</header>

<section class="hero">
  <img src="https://via.placeholder.com/400x240" alt="Product image">
  <div>
    <h2>Designed for learners</h2>
    <p>Write one paragraph about your product.</p>
    <button>Buy Now</button>
  </div>
</section>

<section class="image-fit-lab">
  <div class="fit-cover">cover</div>
  <div class="fit-contain">contain</div>
  <div class="fit-fill">fill</div>
</section>

Deliverable: Styled hero block plus visual comparison of image fit behavior.

Assignment 3: Scenario - Featured Carousel (No JavaScript)

Scenario: You are building a landing page for a small store. The owner wants a moving featured-items carousel using only HTML + CSS.

Objective: Use Flexbox and keyframes to create a CSS-only image carousel.

Questions

  1. Q1 (Core): Build a carousel that auto-slides 3 cards/images horizontally using Flexbox and @keyframes.
  2. Q2 (Challenge): Add :hover pause behavior and label each slide clearly for readability.

Starter HTML

<section class="carousel-wrap">
  <h2>Featured This Week</h2>
  <div class="carousel">
    <div class="slides">
      <article class="slide">Slide 1</article>
      <article class="slide">Slide 2</article>
      <article class="slide">Slide 3</article>
    </div>
  </div>
</section>

Deliverable: Smooth CSS-only carousel with visible card content and no JavaScript.

Assignment 4: Scenario - Interactive Promo Widgets

Scenario: A client asks for a small promo card area that feels interactive and modern.

Objective: Practice transitions and keyframe animations for UI feedback.

Questions

  1. Q1 (Core): Create one button and one card with hover/focus transition effects (color, shadow, move, or scale).
  2. Q2 (Challenge): Build one animated loader/pulse element using @keyframes.

Starter HTML

<section class="promo-ui">
  <h2>New Launch</h2>
  <button class="promo-btn">Explore Offer</button>
  <article class="promo-card">Hover over this card</article>
  <div class="promo-loader" aria-label="Loading"></div>
</section>

Deliverable: One mini promo interface with transition + keyframe animation.

Assignment 5: Scenario - Ecommerce Grid Page

Scenario: You are designing a basic ecommerce layout for desktop and mobile.

Objective: Use CSS Grid to build page structure and product layout blocks.

Questions

  1. Q1 (Core): Build a grid layout with areas: header, sidebar, main, and footer. Inside main, create a product card grid.
  2. Q2 (Challenge): Add a mobile breakpoint so the layout stacks in one column while keeping content clear.

Starter HTML

<div class="shop-layout">
  <header class="shop-header">Store Header</header>
  <aside class="shop-sidebar">Filters / Categories</aside>
  <main class="shop-main">
    <section class="product-grid">
      <article class="product-card">Product 1</article>
      <article class="product-card">Product 2</article>
      <article class="product-card">Product 3</article>
      <article class="product-card">Product 4</article>
    </section>
  </main>
  <footer class="shop-footer">Store Footer</footer>
</div>

Deliverable: Responsive ecommerce mockup using CSS Grid for both page and product layout.
