Core Assignment — Todo API with MongoDB

Build a small todo backend using Node.js, TypeScript, Express, MongoDB (Mongoose), and Zod validation with a clean domain folder structure.

Requirements

  • Express + TypeScript with strict: true and ESM ("type": "module"). Relative imports between src/ files use .ts extensions with noEmit and allowImportingTsExtensions in tsconfig.json.
  • MongoDB connection via Mongoose and DATABASE_URL in .env.
  • Domain folder src/todo/ with controller, routes, service, model, and schema subfolders.
  • Todos CRUD: GET list, GET by id, POST, PUT, PATCH, DELETE.
  • Todo model: title (string), completed (boolean, default false).
  • Zod validation on create/update bodies; return 400 with readable errors.
  • Split app.ts (Express setup + route mounting) and server.ts (startup + listen).
  • GET /health endpoint.
  • README documents env vars, install, run command, and folder structure (3–5 sentences).

Checklist

  • Server starts with one documented command (e.g. npm run dev).
  • Todos persist after server restart.
  • Invalid todo body returns 400 (Zod).
  • Missing todo id returns 404.
  • PATCH can set completed: true.
  • DELETE returns 204.
  • Routes → controller → service → model separation under src/todo/.
  • .env is gitignored; .env.example lists keys without secrets.

Curl test script (include in README or submission log)

Run these in order and capture output:

# Health
curl http://localhost:3000/health

# Create
curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title":"Week 6 Demo"}'

# List
curl http://localhost:3000/todos

# Get one (use _id from create response)
curl http://localhost:3000/todos/TODO_ID

# Full replace
curl -X PUT http://localhost:3000/todos/TODO_ID \
  -H "Content-Type: application/json" \
  -d '{"title":"Updated title","completed":false}'

# Mark complete
curl -X PATCH http://localhost:3000/todos/TODO_ID \
  -H "Content-Type: application/json" \
  -d '{"completed": true}'

# Delete
curl -i -X DELETE http://localhost:3000/todos/TODO_ID

# Invalid create (should 400)
curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title":""}'
