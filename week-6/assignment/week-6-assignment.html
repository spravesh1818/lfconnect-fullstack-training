Core Assignment — Todo API with MongoDB and Auth

Build a small todo backend using Node.js, TypeScript, Express, MongoDB (Mongoose), Zod, and JWT authentication.

Requirements

  • Express + TypeScript with strict: true and ESM ("type": "module").
  • MongoDB connection via Mongoose and DATABASE_URL in .env.
  • Domain-driven folders: at least modules/todos/ and modules/auth/.
  • Todos CRUD: GET list, GET by id, POST, PUT, PATCH, DELETE.
  • Todo model: title (string), completed (boolean, default false).
  • Zod validation on create/update bodies; return 400 with readable errors.
  • Auth: POST /auth/register, POST /auth/login with bcrypt password hashing.
  • JWT middleware protecting mutation routes (POST/PUT/PATCH/DELETE on todos).
  • GET /health endpoint.
  • README documents env vars, install, run command, and folder structure (3–5 sentences).

Checklist

  • Server starts with one documented command (e.g. npm run dev).
  • Todos persist after server restart.
  • Invalid todo body returns 400 (Zod).
  • Missing todo id returns 404.
  • PATCH can set completed: true.
  • DELETE returns 204.
  • Register + login work; passwords are hashed in DB.
  • POST /todos without token returns 401.
  • POST /todos with valid Bearer token returns 201.
  • .env is gitignored; .env.example lists keys without secrets.

Curl test script (include in README or submission log)

Run these in order and capture output:

# Health
curl http://localhost:3000/health

# Register
curl -X POST http://localhost:3000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"name":"Demo User","email":"demo@example.com","password":"demo123456"}'

# Login — save token
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"demo@example.com","password":"demo123456"}'

# Create todo (authenticated)
curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"title":"Week 6 Demo"}'

# List todos (public)
curl http://localhost:3000/todos

# Mark complete
curl -X PATCH http://localhost:3000/todos/TODO_ID \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"completed": true}'

# Unauthenticated create (should 401)
curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title":"Fail"}'
