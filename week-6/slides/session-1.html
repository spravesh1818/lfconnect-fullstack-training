Part 1

Week 5 taught backend concepts with an in-memory array. Restart the server — data gone.

Why we need a database

  • Data survives server restarts
  • Multiple users share the same source of truth
  • You can query, sort, and filter at scale

Week 5 mentioned PostgreSQL and Prisma. This week we use MongoDB because our course is MERN — the concepts transfer.

What is MERN?

  • MongoDB — database
  • Express — Node web framework
  • React — frontend (Weeks 2–4)
  • Node.js — JavaScript runtime on the server

Today we build the E + N + M part — a small todo API before bigger apps later.

Part 2

MongoDB Basics

Think: database → collection → document (like a JSON object).

Key terms

  • Database — container (e.g. todo)
  • Collection — group of documents (e.g. todos)
  • Document — one record, e.g. { title, completed }
  • _id — unique id MongoDB adds automatically

MongoDB Atlas (recommended for class)

  1. Create a free cluster at mongodb.com/atlas
  2. Create a database user with password
  3. Allow your IP (or 0.0.0.0/0 for demos)
  4. Copy the connection string into .env
DATABASE_URL=mongodb+srv://USER:PASS@cluster.mongodb.net/todo

Never commit .env — add it to .gitignore.

What is Mongoose?

  • ODM — Object Document Mapper (like an ORM for MongoDB)
  • Schema — defines allowed fields and types
  • Model — the API you call: find(), create(), findById()

Part 3

Project Setup

Same TypeScript + Express stack as Week 5 — ESM, strict mode, tsx watch.

Step 1 — Initialize

mkdir todo-api && cd todo-api
npm init -y

Add "type": "module" in package.json.

Step 2 — Install packages

npm install express dotenv mongoose
npm install -D typescript tsx @types/node @types/express

Step 3 — tsconfig.json

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "NodeNext",
    "moduleResolution": "NodeNext",
    "strict": true,
    "outDir": "dist",
    "esModuleInterop": true,

Step 4 — Minimal server

import "dotenv/config";
import express from "express";

const app = express();
app.use(express.json());

app.get("/", (_req, res) => res.json({ message: "hello from todo-api" }));
app.get("/health", (_req, res) => res.json({ status: "ok" }));

app.listen(3000, () => console.log("listening on http://localhost:3000"));

Step 5 — Connect MongoDB

// src/config/db.ts
import mongoose from "mongoose";

export async function connectDB() {
  const url = process.env.DATABASE_URL;
  if (!url) throw new Error("DATABASE_URL missing");
  await mongoose.connect(url);
  console.log("MongoDB connected");
}

Call await connectDB() once before app.listen.

Step 6 — Todo model

import { Schema, model } from "mongoose";

const todoSchema = new Schema(
  { title: String, completed: { type: Boolean, default: false } },
  { timestamps: true }
);

export const TodoModel = model("Todo", todoSchema);

timestamps: true adds createdAt and updatedAt automatically.

Part 4

GET and POST Routes

Read list with GET. Create with POST. Use async/await because database calls return Promises.

GET /todos

app.get("/todos", async (_req, res) => {
  try {
    const todos = await TodoModel.find().sort({ createdAt: -1 });
    res.json(todos);
  } catch (err) {
    res.status(500).json({ error: "Failed to fetch todos" });
  }
});

Status 200 — success, body is JSON array.

POST /todos

app.post("/todos", async (req, res) => {
  const { title } = req.body ?? {};
  if (!title || !title.trim()) {
    return res.status(400).json({ error: "title is required" });
  }
  const todo = await TodoModel.create({ title: title.trim() });
  res.status(201).json(todo);
});

Status 201 Created — new resource. Status 400 — client sent bad data.

Test with curl

curl http://localhost:3000/todos

curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title":"Learn MongoDB"}'

Proof of persistence: POST a todo, restart the server, GET again — data still there.

Request flow (today's version)

Client → Express → Route handler → Mongoose → MongoDB
                     ↑
              express.json() parses body on POST

Common beginner mistakes

  • Forgot app.use(express.json()) → req.body is undefined
  • Wrong or missing DATABASE_URL → connection timeout
  • Not using async/await → unhandled promise errors
  • Committed .env to Git → leaked credentials
