Exercise 0 - Setup

  1. Create a working folder: mkdir todo-api && cd todo-api.
  2. Use Node 18+ (check with node -v).
  3. Open the folder in VS Code or Cursor.
  4. Create a free MongoDB Atlas cluster (or run MongoDB locally).
  5. Copy your connection string into a .env file (never commit this file):
DATABASE_URL=mongodb+srv://USER:PASSWORD@cluster0.example.mongodb.net/todo?retryWrites=true&w=majority
  1. Add .env to .gitignore.
Done when: you have an empty project folder, a terminal ready, and a working DATABASE_URL.

Exercise 1 - JavaScript Express skeleton

  1. Initialize the project: npm init -y. Edit package.json and add "type": "module".
  2. Install runtime deps: npm install express dotenv mongoose.
  3. Create src/server.js with hello-world and health endpoints.
  4. Add a script to package.json: "dev": "node --watch src/server.js" (Node 18+).
  5. Run npm run dev and verify both endpoints.
// src/server.js
import "dotenv/config";
import express from "express";

const app = express();
app.use(express.json());

app.get("/", (_req, res) => res.json({ message: "hello from todo-api" }));
app.get("/health", (_req, res) => res.json({ status: "ok" }));

const PORT = process.env.PORT ?? 3000;
app.listen(PORT, () => console.log(`listening on http://localhost:${PORT}`));

Note: We use plain JavaScript today. Class 2 converts this project to TypeScript.

Done when: GET / and GET /health return JSON in the browser or with curl.

Exercise 2 - Connect MongoDB with Mongoose

  1. Create src/config/db.js to connect once at startup.
  2. Import and call connectDB() in server.js before app.listen.
  3. Restart the server and confirm you see MongoDB connected in the terminal.
// src/config/db.js
import mongoose from "mongoose";

export async function connectDB() {
  const url = process.env.DATABASE_URL;
  if (!url) throw new Error("DATABASE_URL is missing in .env");
  await mongoose.connect(url);
  console.log("MongoDB connected");
}
// src/server.js (add near the top of startup)
import { connectDB } from "./config/db.js";

await connectDB();

Why .js in the import? The file on disk is db.js, so the import matches it. In Class 2 you rename to db.ts and import from "./config/db.ts".

What this does: Mongoose opens one connection pool. Routes reuse it — you do not connect on every request.

Done when: server starts without connection errors and logs MongoDB connected.

Exercise 3 - Todo model

  1. Create src/models/todo.model.js.
  2. A schema defines the shape of documents. A model is the class you call (find, create).
// src/models/todo.model.js
import { Schema, model } from "mongoose";

const todoSchema = new Schema(
  {
    title: { type: String, required: true },
    completed: { type: Boolean, default: false },
  },
  { timestamps: true }
);

export const TodoModel = model("Todo", todoSchema);
Done when: the server starts with no import errors.

Exercise 4 - GET and POST /todos (persisted)

  1. Add routes below your health check in server.js (we refactor into folders in Class 2).
  2. Use async handlers and try/catch for database errors.
  3. Validate title manually with an if check (Zod comes in Class 2).
  4. Test with curl — then restart the server and GET again to prove data survived.
import { TodoModel } from "./models/todo.model.js";

app.get("/todos", async (_req, res) => {
  try {
    const todos = await TodoModel.find().sort({ createdAt: -1 });
    res.json(todos);
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Failed to fetch todos" });
  }
});

app.post("/todos", async (req, res) => {
  try {
    const { title } = req.body ?? {};
    if (!title || typeof title !== "string" || !title.trim()) {
      return res.status(400).json({ error: "title is required" });
    }
    const todo = await TodoModel.create({ title: title.trim() });
    res.status(201).json(todo);
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: "Failed to create todo" });
  }
});

Test commands:

curl http://localhost:3000/todos

curl -X POST http://localhost:3000/todos \
  -H "Content-Type: application/json" \
  -d '{"title":"Learn MongoDB"}'
Done when: POST returns 201, GET returns the todo, data persists after server restart, and missing title returns 400.

Lab checklist

  • Server boots with npm run dev.
  • GET /health returns { status: "ok" }.
  • MongoDB connects successfully via Atlas (or local).
  • GET /todos returns an array (empty at first).
  • POST /todos creates a document in MongoDB.
  • Todos still exist after restarting the server.
  • Invalid POST (missing title) returns 400.
  • All code is plain .js files under src/.

Troubleshooting

  • MongooseServerSelectionError / timeout — check Atlas IP allowlist (add 0.0.0.0/0 for class demos), username/password, and cluster URL.
  • DATABASE_URL is missing — ensure .env is in project root and you import dotenv/config at the top of server.js.
  • req.body is undefined on POST — add app.use(express.json()) before routes.
  • Empty array after POST — confirm POST returned 201 and you are hitting the same database URL.
  • node --watch not found — upgrade to Node 18+, or use npm install -D nodemon and "dev": "nodemon src/server.js".
