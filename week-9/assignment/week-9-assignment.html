Full checklist

Part 1 — Stripe Webhooks

  • Stripe SDK installed; client initialised from STRIPE_SECRET_KEY env var
  • POST /webhooks/stripe registered before express.json()
  • Uses express.raw() body parser on the webhook route
  • Signature verified with stripe.webhooks.constructEvent()
  • Returns 400 with descriptive message on invalid signature
  • Handles payment_intent.succeeded — logs PI id and amount
  • Returns { received: true } with 200 on success
  • Stripe CLI shows 200 when you run stripe trigger payment_intent.succeeded
  • .env has both STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET
  • .env is in .gitignore

Part 2 — NestJS Scaffold

  • npm run start:dev starts without errors
  • TypeORM connects to PostgreSQL on startup
  • user, room, and meeting tables auto-created
  • GET /rooms returns empty array or list of rooms
  • GET /rooms/:id returns a room or 404
  • POST /rooms creates a room and returns it
  • Services injected via constructor (no new ServiceClass())
  • Repositories injected with @InjectRepository(Entity)
  • .env.example committed with placeholder DB values

Part 3 — Sprint Plan

  • GitHub Project board created with Backlog / In Progress / Done columns
  • 5+ GitHub Issues created for meeting-app features
  • Each issue has a user story and acceptance criteria in the body
  • Each issue has a size label (size:S, size:M, or size:L)
  • Sprint 1 milestone created with a due date
  • All issues assigned to the Sprint 1 milestone
  • Sprint goal written as project description or pinned issue
