Exercise 2 - Install TypeORM and Postgres dependencies

npm install @nestjs/typeorm typeorm pg

Start a local Postgres database (Docker is the easiest way):

docker run -d \
  --name meeting-db \
  -e POSTGRES_USER=meeting \
  -e POSTGRES_PASSWORD=secret \
  -e POSTGRES_DB=meeting_dev \
  -p 5432:5432 \
  postgres:16

Create a .env file at the project root:

DB_HOST=localhost
DB_PORT=5432
DB_USER=meeting
DB_PASS=secret
DB_NAME=meeting_dev

Install config support:

npm install @nestjs/config
Done when: docker ps shows the container running and .env exists.

Exercise 3 - Wire TypeORM in AppModule

Update src/app.module.ts:

import { Module } from "@nestjs/common";
import { ConfigModule, ConfigService } from "@nestjs/config";
import { TypeOrmModule } from "@nestjs/typeorm";
import { AppController } from "./app.controller";
import { AppService } from "./app.service";

@Module({
  imports: [
    ConfigModule.forRoot({ isGlobal: true }),
    TypeOrmModule.forRootAsync({
      inject: [ConfigService],
      useFactory: (config: ConfigService) => ({
        type: "postgres",
        host: config.get("DB_HOST"),
        port: +config.get("DB_PORT")!,
        username: config.get("DB_USER"),
        password: config.get("DB_PASS"),
        database: config.get("DB_NAME"),
        autoLoadEntities: true,
        synchronize: true,   // dev only
      }),
    }),
  ],
  controllers: [AppController],
  providers: [AppService],
})
export class AppModule {}
Done when: npm run start:dev starts with no errors and logs TypeORM connected (or no connection error).

Exercise 4 - Generate UsersModule and UserEntity

nest g module users
nest g controller users --no-spec
nest g service users --no-spec

Create src/users/entities/user.entity.ts:

import {
  Entity, PrimaryGeneratedColumn, Column,
  CreateDateColumn, UpdateDateColumn
} from "typeorm";

@Entity()
export class User {
  @PrimaryGeneratedColumn("uuid")
  id: string;

  @Column({ unique: true })
  email: string;

  @Column()
  displayName: string;

  @Column()
  passwordHash: string;

  @Column({ nullable: true })
  avatarUrl: string;

  @CreateDateColumn()
  createdAt: Date;

  @UpdateDateColumn()
  updatedAt: Date;
}

Register the entity in src/users/users.module.ts:

import { Module } from "@nestjs/common";
import { TypeOrmModule } from "@nestjs/typeorm";
import { User } from "./entities/user.entity";
import { UsersController } from "./users.controller";
import { UsersService } from "./users.service";

@Module({
  imports: [TypeOrmModule.forFeature([User])],
  controllers: [UsersController],
  providers: [UsersService],
  exports: [UsersService],
})
export class UsersModule {}

Import UsersModule in AppModule.

Done when: the server starts and you can see a user table in your Postgres database (docker exec -it meeting-db psql -U meeting -d meeting_dev -c "\dt").

Exercise 5 - Generate RoomsModule and RoomEntity

nest g resource rooms --no-spec

Create src/rooms/entities/room.entity.ts:

import {
  Entity, PrimaryGeneratedColumn, Column,
  ManyToOne, CreateDateColumn
} from "typeorm";
import { User } from "../../users/entities/user.entity";

@Entity()
export class Room {
  @PrimaryGeneratedColumn("uuid")
  id: string;

  @Column()
  name: string;

  @Column({ nullable: true })
  description: string;

  @Column({ default: 50 })
  maxParticipants: number;

  @ManyToOne(() => User, { nullable: true })
  host: User;

  @CreateDateColumn()
  createdAt: Date;
}

Register Room in RoomsModule and import RoomsModule in AppModule.

Done when: server restarts and a room table appears in Postgres.

Exercise 6 - Add a basic findAll endpoint (stretch)

In src/rooms/rooms.service.ts:

import { Injectable } from "@nestjs/common";
import { InjectRepository } from "@nestjs/typeorm";
import { Repository } from "typeorm";
import { Room } from "./entities/room.entity";

@Injectable()
export class RoomsService {
  constructor(
    @InjectRepository(Room)
    private readonly roomRepo: Repository<Room>,
  ) {}

  findAll() {
    return this.roomRepo.find({ relations: ["host"] });
  }

  create(data: Partial<Room>) {
    const room = this.roomRepo.create(data);
    return this.roomRepo.save(room);
  }
}

In rooms.controller.ts, add @Get() and @Post() routes that call the service.

Done when: GET http://localhost:3000/rooms returns an empty array [].

Troubleshooting

  • connect ECONNREFUSED 127.0.0.1:5432 — Postgres is not running. Start the Docker container.
  • password authentication failed — credentials in .env don't match the Docker container. Re-check DB_USER and DB_PASS.
  • Entity not found by TypeORM — you probably forgot to register it in the module's TypeOrmModule.forFeature([Entity]) call.
  • Cannot find module '../entities/user.entity' — check the relative import path. NestJS uses TypeScript paths.
