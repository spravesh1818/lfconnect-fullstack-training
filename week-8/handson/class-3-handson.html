Mini-lab A — Passport.js (Express)

A1 - Install and configure local strategy

In your Todo API repo (or a minimal Express app):

npm install passport passport-local
npm install -D @types/passport @types/passport-local
import passport from "passport";
import { Strategy as LocalStrategy } from "passport-local";

passport.use(new LocalStrategy(
  { usernameField: "email" },
  async (email, password, done) => {
    const user = await UserModel.findOne({ email });
    if (!user) return done(null, false);
    const ok = await bcrypt.compare(password, user.passwordHash);
    if (!ok) return done(null, false);
    return done(null, user);
  }
));
Done when: strategy registered without startup errors.

A2 - Passport login route

app.post("/auth/passport-login",
  passport.authenticate("local", { session: false }),
  (req, res) => {
    const token = jwt.sign({ sub: req.user.id }, process.env.JWT_SECRET!, {
      expiresIn: "7d",
    });
    res.json({
      token,
      user: { id: req.user.id, name: req.user.name, email: req.user.email },
    });
  }
);
curl -X POST http://localhost:3000/auth/passport-login \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"yourpassword"}'
Done when: response matches your existing /auth/login shape.

Mini-lab B — Supabase Auth (React)

B1 - Create Supabase project

  1. Sign up at supabase.com
  2. Create a new project
  3. Settings → API → copy Project URL and anon public key
  4. Authentication → Providers → ensure Email is enabled
Done when: you have URL and anon key ready.

B2 - Vite + Supabase client

npm create vite@latest supabase-sandbox -- --template react-ts
cd supabase-sandbox
npm install @supabase/supabase-js
# .env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=your_anon_key
import { createClient } from "@supabase/supabase-js";

export const supabase = createClient(
  import.meta.env.VITE_SUPABASE_URL,
  import.meta.env.VITE_SUPABASE_ANON_KEY
);
Done when: client initializes without env errors.

B3 - Register, login, display session

// Register
await supabase.auth.signUp({ email, password });

// Login
const { data, error } = await supabase.auth.signInWithPassword({
  email, password,
});

// Logout
await supabase.auth.signOut();

Build three buttons and show data.session?.user.email plus a JSON dump of the session on screen.

Done when: you can sign up a test user, log in, see email, and log out.

Mini-lab C — Clerk (React)

C1 - Create Clerk application

  1. Sign up at clerk.com
  2. Create an application
  3. Copy the Publishable key
  4. Configure allowed origins: http://localhost:5173
Done when: publishable key is ready.

C2 - Vite + ClerkProvider

npm create vite@latest clerk-sandbox -- --template react-ts
cd clerk-sandbox
npm install @clerk/clerk-react react-router-dom
# .env
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
import { ClerkProvider, SignIn, SignUp, UserButton } from "@clerk/clerk-react";
import { BrowserRouter, Routes, Route } from "react-router-dom";

const pk = import.meta.env.VITE_CLERK_PUBLISHABLE_KEY;

export default function App() {
  return (
    <ClerkProvider publishableKey={pk}>
      <BrowserRouter>
        <header><UserButton /></header>
        <Routes>
          <Route path="/sign-in" element={<SignIn />} />
          <Route path="/sign-up" element={<SignUp />} />
          <Route path="/" element={<p>Home — sign in to continue</p>} />
        </Routes>
      </BrowserRouter>
    </ClerkProvider>
  );
}
Done when: SignIn and SignUp pages render; UserButton appears when signed in.
