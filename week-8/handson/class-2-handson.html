Exercise 4 - apiFetch helper

Create src/api/client.ts:

const API_URL = import.meta.env.VITE_API_URL;

export async function apiFetch(path: string, options: RequestInit = {}) {
  const token = localStorage.getItem("token");
  const headers = new Headers(options.headers);
  if (token) headers.set("Authorization", `Bearer ${token}`);
  const res = await fetch(`${API_URL}${path}`, { ...options, headers });
  if (res.status === 401) {
    localStorage.removeItem("token");
    localStorage.removeItem("user");
    window.location.href = "/login";
    throw new Error("Unauthorized");
  }
  return res;
}
Done when: helper is used by auth and todo calls; 401 redirects to login.

Exercise 7 - ProtectedRoute + logout

function ProtectedRoute({ children }: { children: React.ReactNode }) {
  const { token } = useAuth();
  if (!token) return <Navigate to="/login" replace />;
  return <>{children}</>;
}

Wrap /todos with ProtectedRoute. Add logout button that clears auth and navigates to /login.

Visit /todos while logged out — should redirect.

Done when: unauthenticated users cannot see todos page; logout works.

Troubleshooting

  • CORS error in console — add cors({ origin: "http://localhost:5173" }) on API; restart server.
  • VITE_API_URL undefined — file must be .env at project root; restart Vite after changes.
  • 401 on every todo request — token not sent; check Authorization header spelling.
  • Network error — API not running on 3000.
  • Upload fails — do not set Content-Type manually on FormData.
  • Blank page after login — check React Router paths and Navigate import.
