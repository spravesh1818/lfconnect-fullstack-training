Exercise 2 - Export queue

Create src/queues/todo.queue.ts:

import { Queue } from "bullmq";

const connection = { url: process.env.REDIS_URL ?? "redis://localhost:6379" };

export const todoExportQueue = new Queue("todo-export", { connection });
Done when: queue module exports without TypeScript errors.

Exercise 3 - Enqueue from API

Add a protected route POST /todos/export:

import { todoExportQueue } from "../queues/todo.queue.ts";

export async function exportTodos(req: Request, res: Response) {
  const job = await todoExportQueue.add("export-todos", {
    requestedBy: req.userId,
  });
  res.status(202).json({ jobId: job.id, status: "queued" });
}

Mount with requireAuth. Response must return in under 1 second even though work takes longer.

Done when: curl returns 202 with a jobId immediately.

Exercise 4 - Worker process

Create src/workers/todo.worker.ts:

import { Worker } from "bullmq";
import fs from "node:fs/promises";
import path from "node:path";
import { connectDB } from "../config/db.ts";
import { TodoModel } from "../todo/model/todo.model.ts";

const connection = { url: process.env.REDIS_URL ?? "redis://localhost:6379" };

await connectDB();

new Worker(
  "todo-export",
  async (job) => {
    if (job.name !== "export-todos") return;

    console.log("Worker started job", job.id);
    await new Promise((r) => setTimeout(r, 5000));

    const todos = await TodoModel.find().lean();
    const filePath = path.join("exports", `todos-${job.id}.json`);
    await fs.writeFile(filePath, JSON.stringify(todos, null, 2));

    console.log("Worker finished job", job.id, "→", filePath);
    return { filePath, count: todos.length };
  },
  { connection }
);

console.log("Todo export worker listening...");

Run in a second terminal: npm run worker

Done when: worker logs start + finish after you POST /todos/export.

Exercise 6 - Multer attachment upload (optional but recommended)

Create src/middleware/upload.ts:

import multer from "multer";

export const todoUpload = multer({
  dest: "uploads/",
  limits: { fileSize: 2 * 1024 * 1024 },
});

Add route POST /todos/:id/attachment with requireAuth and todoUpload.single("file"). Save req.file.path on the todo document (add optional attachmentPath field).

curl -X POST http://localhost:3000/todos/TODO_ID/attachment \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "file=@./notes.txt"
Done when: response JSON includes the saved file path under uploads/.

Troubleshooting

  • Job stays queued forever — worker terminal not running; queue name must match (todo-export).
  • Worker MongoDB error — call connectDB() in worker before queries.
  • ECONNREFUSED on export — Redis not running; same REDIS_URL in both processes.
  • Multer LIMIT_FILE_SIZE — file exceeds 2 MB limit.
  • req.file undefined — curl must use -F and field name file.
