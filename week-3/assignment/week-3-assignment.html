Assignment 1: Live Digital Clock with useEffect

Objective: Build one small standalone React component to practice useEffect and cleanup safely.

  1. Create a component called LiveClock.
  2. Use useState to store the current Date.
  3. Use useEffect with setInterval to update the state every second.
  4. Return a cleanup function that calls clearInterval.
  5. Display the time as HH:MM:SS (date line is optional).

Deliverable: One component file plus a screenshot or short note proving the clock updates every second.

Hints:
  • setInterval returns an id. Save it and pass it to clearInterval in cleanup.
  • The effect can use an empty dependency array ([]) for this case.

Assignment 2: Build Meeting Basum with React Router

Objective: Recreate the UI shown in these screenshots using React Router features from Week 3.

  1. Set up BrowserRouter once at root and create an app-shell layout route with persistent sidebar, top header, footer, and <Outlet />.
  2. Use NavLink in the sidebar for: /, /new-meeting, /join-meeting, /calendar, /schedule-meeting, and /profile-settings.
  3. Build the dashboard route with 3 quick-action cards and an upcoming meetings list from a local hardcoded array.
  4. Each upcoming meeting row should navigate to /meetings/:meetingId using useNavigate. Read the id with useParams.
  5. Inside /meetings/:meetingId, create nested routes (details and participants) rendered through another <Outlet /> with relative NavLinks.
  6. On /calendar, implement ?view=month|week switching via useSearchParams.
  7. Add a catch-all route (path="*") with a friendly Not Found page and link back home.

Deliverable: Working screenshot-matched app plus a short ROUTES.md listing each route, what it renders, and which router hook(s) it uses.
