Week 3 - Class 3 Lab - Open session deck - Advanced React Router, useMemo/useCallback, custom hooks, and HOF patterns

Exercise 1 - Advanced Routing

  1. Add a dynamic route (e.g. /items/:itemId) and read itemId with useParams.
  2. Use useSearchParams for at least one filter or tab encoded in the query string (e.g. ?sort=price).
  3. Create a nested layout route with Outlet (e.g. parent path + two child segments).
  4. Add an app shell: a parent layout route with persistent header or nav (and optional footer) plus <Outlet /> where nested pages render — matching the Session 3 app-shell slides.
Done when: chrome stays mounted while inner routes change; direct URLs and refreshes preserve param/query state.

Exercise 2 - Optimize Derived Data Carefully

  1. Add expensive list filtering or sorting logic to a component.
  2. Use useMemo only for computations that are measurably expensive.
  3. Document one place where memoization is not necessary.
Done when: memoization has a clear reason, not just blanket usage.

Exercise 3 - Extract Reusable Custom Hook

  1. Create a useDebouncedValue or useAsyncResource hook.
  2. Use it in at least two components.
  3. Confirm dependencies and cleanup logic are correct.
Done when: duplicated logic is removed and hook behavior is stable.

Exercise 4 - Apply Higher-Order Functions

  1. Refactor data handling using map, filter, and reduce.
  2. Create one utility function for reusable transform logic.
  3. Keep components focused on rendering and composition.
Done when: data transforms are readable, testable, and detached from UI clutter.
