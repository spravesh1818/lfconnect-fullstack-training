Week 3 - Class 3 Lab - Open session deck - Context, Zustand, Tailwind, Chakra UI, Docker, and Netlify

Exercise 1 - Add Global State Layer

  1. Implement shared state once with Context and once with Zustand (small feature scope).
  2. Compare boilerplate, readability, and update performance.
  3. Keep local UI state local; move only truly shared state globally.
Done when: both approaches work and you can explain when to use each.

Exercise 2 - Styling Strategy

  1. Use Tailwind for layout and spacing.
  2. Use Chakra UI for required reusable UI components.
  3. Try one optional extension with Radix UI primitive for contrast.
Done when: app has coherent design system and accessibility-friendly components.

Exercise 3 - Dockerize and Deploy

  1. Create production build and lightweight Dockerfile.
  2. Verify app runs in container locally.
  3. Deploy app to Netlify and document deployment URL.
Done when: deployment is live and reproducible from repository instructions.
