Week 3 - Class 2 Lab - Open session deck - React Router foundations only (BrowserRouter, Routes, Link/NavLink, 404)

Exercise 1 - React Router in Your App

  1. Install react-router and wrap your app (or App) with BrowserRouter.
  2. Define at least three routes (for example / Home, /about About, plus a catch-all * for a simple NotFound page).
  3. Add a small nav using NavLink with a visible active state (e.g. via className callback or styles).
  4. Confirm in-app navigation does not full-reload the page; unknown paths show your 404 view.
Done when: all three routes work, active link styling is obvious, and unmatched URLs hit NotFound.
