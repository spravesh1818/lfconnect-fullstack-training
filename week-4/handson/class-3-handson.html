Week 4 - Class 3 Lab - Open session deck - JWT auth, protected routes, TypeScript

Exercise 1 - Login with JWT in localStorage

  1. Create AuthProvider with login, logout, user, token.
  2. Implement mock login (or real API) returning { token, user }.
  3. Persist token with localStorage.setItem("access_token", …).
  4. Logout removes token and clears auth state.
Done when: refresh keeps you logged in; logout clears access.

Exercise 2 - Protected Routes

  1. Build ProtectedRoute that redirects to /login when token is missing.
  2. Wrap dashboard/app routes; keep /login public.
  3. After login, redirect to intended page using location.state.from.
  4. Attach Authorization: Bearer … on at least one API fetch.
Done when: direct URL to protected route while logged out sends you to login.

Exercise 3 - TypeScript Migration

  1. Convert at least 2 files to .tsx / .ts (e.g. form component + table component).
  2. Add prop types and typed form data (useForm<MeetingInput>).
  3. Type table columns with ColumnDef<Meeting>[].
  4. Write 3–5 lines on localStorage vs httpOnly cookies for JWT storage.
Done when: npm run build passes and auth tradeoffs note is in README or submission.
