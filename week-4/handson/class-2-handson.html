Week 4 - Class 2 Lab - Open session deck - classical forms, react-hook-form, Zod, and @tanstack/react-table

Exercise 0 (optional) - Classical Controlled Form

  1. Build Schedule Meeting with useState for form and errors.
  2. Use value + onChange on each input.
  3. On submit: preventDefault, run a validate() function, show errors, block invalid submit.
Done when: you can explain controlled inputs without a form library.

Exercise 1 - Schedule Meeting (react-hook-form)

  1. Install react-hook-form.
  2. Rebuild the form with register, handleSubmit, and inline validation rules first.
  3. Display field errors under inputs; block submit when invalid.
Done when: RHF version works and you can compare it to Exercise 0.

Exercise 1b - Add Zod validation

  1. Install zod and @hookform/resolvers.
  2. Create meetingSchema with rules for title, date, and participants.
  3. Wire zodResolver(meetingSchema) into useForm.
  4. Remove duplicate inline rules from register calls.
Done when: all validation rules live in the Zod schema.

Exercise 2 - Upcoming Meetings Table (TanStack Table)

  1. Install @tanstack/react-table.
  2. Render upcoming meetings with at least 3 columns (title, host, time) plus a Join/action column.
  3. Enable column sorting with getSortedRowModel.
  4. On valid form submit from Exercise 1b, append a row to the table data.
Done when: table sorts by header click and new meetings appear after submit.
