Assignment 1 (Session 1): Global State to Deployment

Objective: Production-style workflow from state architecture to hosting.

  1. Implement shared state with Context API and Zustand (comparison-based task).
  2. Style app with Tailwind and use Chakra UI as the required component library.
  3. Try one optional UI primitive using Radix UI and note when it is useful.
  4. Dockerize the app and deploy to Netlify.

Deliverable: Running deployment URL, Docker setup, and short architecture decision note.

Assignment 2 (Session 2): Forms and Tables

Objective: Add validated forms and a sortable data table to Meeting Basum.

  1. Build Schedule Meeting form with react-hook-form.
  2. Validate with a Zod schema and @hookform/resolvers/zod (not only inline register rules).
  3. Build Upcoming Meetings table with @tanstack/react-table (sort + action column).
  4. Connect valid form submit to meetings data shown in the table.
  5. Optional: short README note comparing classical useState forms vs react-hook-form.

Deliverable: Working Zod-backed form and sortable table integrated into the routed app.

Assignment 3 (Session 3): Auth and TypeScript

Objective: Protect routes with JWT demo auth and add TypeScript to key modules.

  1. Implement login/logout with JWT stored in localStorage (mock API OK).
  2. Add ProtectedRoute for dashboard/app routes; keep /login public.
  3. Attach Authorization: Bearer on at least one API request.
  4. Convert at least 2 components/files to TypeScript with meaningful types.
  5. Write a short note comparing localStorage vs httpOnly cookies for token storage.

Deliverable: Auth flow demo + typed modules + auth tradeoffs note in README or submission.
